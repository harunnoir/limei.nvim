==============================================================================
INTRODUCTION                                                          *limei*

limei.nvim is a deeply dark, muted colorscheme for Neovim 0.10 and newer.
Its interface is emotionally neutral and quiet without blue dominance. Major
code categories have distinct semantic identities while ordinary structure
and plugin surfaces remain neutral.

==============================================================================
SETUP                                                            *limei-setup*

The colorscheme works without configuration: >

  :colorscheme limei
<
Optional Lua setup: >

  require("limei").setup({
    transparent = false,
    terminal_colors = true,
    matching = {
      brackets = true,
      quotes = true,
    },
  })
  vim.cmd.colorscheme("limei")
<
==============================================================================
OPTIONS                                                        *limei-options*

transparent       Remove active and inactive editor canvas backgrounds.
                  Floating windows and popup menus remain opaque.

dim_inactive      Deprecated compatibility option. Accepted but visually
                  ineffective; active and inactive windows share a background.

terminal_colors   Install the muted 16-color terminal palette. Default: true.

matching          Enable Neovim's built-in asymmetric bracket matcher and
                  Limei's Tree-sitter-aware same-character delimiter matcher.
                  Both use bold muted-warning emphasis without a background.
                  Set matching.brackets or matching.quotes to false to disable
                  Limei's activation.

styles            Optional attributes for comments, keywords, functions, and
                  variables.

palette           Palette overrides applied before highlights are generated.

highlights        A table or function returning final highlight overrides.

==============================================================================
COMMANDS                                                      *limei-commands*

There are no custom commands. Use |:colorscheme| and the Lua setup API.
